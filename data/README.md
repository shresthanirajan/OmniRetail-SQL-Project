\# OmniRetail SQL Project



A real-world SQL data project focused on building a raw-to-clean data pipeline and solving business problems using SQL Server.



\## Project Goals



\- Import raw CSV data into SQL Server

\- Preserve raw source data

\- Profile and investigate data quality issues

\- Clean and standardize messy data

\- Build trusted clean tables

\- Analyze sales, customers, products, inventory, payments, shipping, returns, support, and marketing

\- Practice real-world SQL problem solving



\## Technologies



\- SQL Server

\- SQL Server Management Studio (SSMS)

\- SQL

\- Git

\- GitHub
